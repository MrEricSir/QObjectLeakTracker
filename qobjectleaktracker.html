    Detailed Description

    Object tracking is performed via Qt's private API and may not be stable between versions.

    Only used for debug builds. In release builds, all functions are no-ops.

    Basic Usage

    Call install() in main() before creating any QObjects:

    int main(int argc, char *argv[])
{
    QObjectLeakTracker::install();

    //
    // Your application code goes here.
    //

    QObjectLeakTracker::printRemaining();
    return 0;
}

    Prefix whitelist

    By default, printRemaining() reports all QObjects, including Qt internals (QNetworkReply, QTimer, etc.) Add prefixes to limit reports to your own classes:

    QObjectLeakTracker::addPrefix("MyApp");
QObjectLeakTracker::addPrefix("MyObjectType");

    Only classes whose names start with a registered prefix will appear in printRemaining(), snapshot(), and remainingCount().

    Scope Helper

    Use the convenience macros to assert that a code block does not allocate any QObjects:

    QLEAK_NO_ALLOC_SCOPE();
// ... code that should not create QObjects ...
QLEAK_ASSERT_NO_ALLOC();

    See also QObjectLeakTracker::Scope.

    Member Function Documentation

    [static] void QObjectLeakTracker::addPrefix(const QString &prefix)

    Registers prefix for class name whitelisting used in reporting.

    When at least one prefix has been registered, printRemaining(), snapshot(), and remainingCount() will only consider objects whose metaObject()->className() starts with one of the registered prefixes.

    By default, the whitelist is empty and all QObject-derived classes will be reported, including Qt internal classes.

    QObjectLeakTracker::addPrefix("MyApp");

    See also printRemaining(), snapshot(), and remainingCount().

    [static] void QObjectLeakTracker::install()

    Installs the leak tracker by hooking into Qt's private API.

    Call this at the very beginning of main(), before constructing a QApplication or any other QObject.

    [static] void QObjectLeakTracker::printRemaining()

    Prints a summary of all remaining (not yet destroyed) QObjects.

    The output includes a count of remaining objects and their type, depending on the log verbosity level.

    Output depends on whitelist.

    See also snapshot(), remainingCount(), and addPrefix().

    [static] int QObjectLeakTracker::remainingCount()

    Returns the number of tracked QObjects that have not been destroyed.

    Output depends on whitelist and build type (returns 0 in release builds.)

    See also snapshot() and printRemaining().

    [static] QMap<QString, int> QObjectLeakTracker::snapshot()

    Returns a map from class name to instance count for all QObjects that have not been destroyed.

    Output depends on whitelist.

    See also remainingCount() and printRemaining().

    [static] qint64 QObjectLeakTracker::totalCreated()

    Returns the total number of QObjects created. Note that this number does not take the whitelist into account.

    See also totalDestroyed().

    [static] qint64 QObjectLeakTracker::totalDestroyed()

    Returns the total number of QObjects destroyed. Note that this number does not take the whitelist into account.

    See also totalCreated().

    Macro Documentation

    QLEAK_ASSERT_NO_ALLOC()

    Asserts that no QObjects have been created since the most recent QLEAK_NO_ALLOC_SCOPE() in the same block. Triggers Q_ASSERT on failure.

    See also QLEAK_NO_ALLOC_SCOPE() and QObjectLeakTracker::Scope.

    QLEAK_NO_ALLOC_SCOPE()

    Declares a QObjectLeakTracker::Scope variable for the current block. Use together with QLEAK_ASSERT_NO_ALLOC() to verify that no QObjects are created within the block.

    See also QLEAK_ASSERT_NO_ALLOC() and QObjectLeakTracker::Scope.
