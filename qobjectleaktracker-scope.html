    Detailed Description

    Construct a Scope on the stack to capture a baseline. Then call created() and destroyed() to find out how many QObjects were allocated or freed since the Scope was constructed.

    {
    QObjectLeakTracker::Scope scope;
    auto *obj = new QObject;
    // scope.created() == 1
    delete obj;
    // scope.destroyed() == 1
}

    See also QObjectLeakTracker, QLEAK_NO_ALLOC_SCOPE(), and QLEAK_ASSERT_NO_ALLOC().
